# Nearest Bin

A Flask web application that finds the nearest public waste bin using OpenStreetMap's Overpass API.

## Features

- Finds nearest public bin
- Calculates distance using the Haversine formula
- Automatic retry if API times out
- Uses cached data if the API is unavailable
- Simple Flask web interface
